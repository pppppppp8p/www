**NAGŁÓWEK:**


**4 ELEMENTY AKORDEONU:**

```
▸ Marka nie oddaje tego, czym naprawdę jesteście
  [rozwinięcie]: Dobry produkt, ale żadna narracja. Właściciel czuje,
  że marka to nie to. Po warsztacie: jasna tożsamość, nazwane wartości,
  opisane wyróżniki. Wiesz co mówić — i możesz to wytłumaczyć każdemu
  nowemu pracownikowi.

▸ Działa, ale nikt nie wie dlaczego
  [rozwinięcie]: Firma działa dobrze "na wyczucie", ale nie ma ram.
  Nowe osoby trudno wdrożyć, decyzje komunikacyjne trudno podjąć.
  Po procesie: nazwane reguły, gotowy język dla całego zespołu.

▸ Strategia w szufladzie
  [rozwinięcie]: Strategia gdzieś zapisana, której nikt nie używa.
  Po procesie: jasna ścieżka, wyznaczone priorytety, zaplanowany
  proces zmiany — nie kolejny plik PDF.

▸ Klienci wychodzą, ale nie wracają
  [rozwinięcie]: Klienci są zadowoleni, ale nie polecają. Po procesie:
  zaprojektowane punkty styku, przemyślane momenty — marka, o której
  ludzie chcą mówić innym.
```

## SEKCJA 02 — TRZY TRYBY PRACY
*Typ: 3 karty lub bloki. Nazwa + jednozdaniowy opis + lista.*

**KARTA 1:**
```
NAGŁÓWEK: 01 / Rozmowa i diagnoza
JEDNOZDANIOWO: Jednorazowe spotkanie, które często zmienia więcej niż rok planowania.

ZAWIERA:
— Pierwsze spotkanie diagnostyczne — zawsze bezpłatne
— Konsultacja ad hoc na konkretny problem
— Burza mózgów i szybka ocena strategiczna

DLA KOGO:
Nie wiesz od czego zacząć. Masz jeden konkretny dylemat. Coś nie gra, ale jeszcze tego nie nazwałeś.
```

**KARTA 2:**
```
NAGŁÓWEK: 02 / Warsztat i strategia
JEDNOZDANIOWO: Wychodzisz ze strategią — nie z notatkami.

ZAWIERA:
— Warsztat strategiczny dla marki (1–2 dni)
— Projektowanie strategii doświadczeń
— Customer Journey Design
— Service Design
— Szkolenia i wykłady
— Wdrożenie projektu online

DLA KOGO:
Rebranding, pivot, nowy start. Klienci nie polecają i nie wiesz dlaczego.
Marka nie oddaje tego, czym naprawdę jesteś.
```

**KARTA 3:**
```
NAGŁÓWEK: 03 / Długoterminowe partnerstwo
JEDNOZDANIOWO: Zewnętrzny strateg, który rozumie kontekst od środka.

ZAWIERA:
— Stały partner strategiczny
— Prowadzenie projektu end-to-end
— Projektowanie i produkcja wydarzeń
— Mentoring wewnętrznego zespołu

DLA KOGO:
Projekt wymagający ciągłości. Chcesz partnera, nie dostawcę. Budujesz coś nowego od podstaw.
```

```
  naprawdę problemem. Zazwyczaj to nie to, z czym klient przychodzi.

▸ Nie akceptuję briefu na ślepo.
  [rozwinięcie]: Klient zgłasza problem A. Po rozmowie okazuje się,

  z największych wartości, jakie oferuję.

▸ Nie sprzedaję dokumentów.
  [rozwinięcie]: Strategia w PDF-ie bez procesu, który do niej
  doprowadził, ma wartość streszczenia książki. Zmiana myślenia
  to produkt główny. Dokument to efekt uboczny.

▸ Mówię to, co widzę — nie to, co chcesz usłyszeć.
  [rozwinięcie]: Nie sprzedaję trików. Buduję fundamenty.
```
